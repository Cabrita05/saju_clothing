Falta conectar

El panel necesita una base de datos de Supabase. Pasos:

  1. Crear un proyecto en supabase.com.
  2. En SQL Editor, pegar y ejecutar el archivo supabase/schema.sql.
  3. En Authentication → Sign In / Providers, desactivar "Allow new users to sign up".
  4. Crear el usuario administrador y agregarlo a la tabla admins (está explicado al final del archivo SQL).
  5. Copiar la URL del proyecto y la clave pública en config.js.
